# ShootingProject Unreal

Unreal Engine의 Blueprint와 입력 기능을 익히기 위해 만든 학습용 프로젝트임.

- GitHub 백업: 2025.09.30
- 구분: Unreal Engine 개인 실습
- 기술: Unreal Engine 5.4, Blueprint, Enhanced Input

## 연습한 내용

- `BP_Player`를 만들고 Blueprint에서 캐릭터 이동을 연결했음.
- Enhanced Input의 가로·세로 입력 액션과 Mapping Context를 나눠 설정했음.
- `MainMap`과 기본 게임 모드를 구성했음.
- Starter Content를 이용해 기본 씬을 확인했음.

## 현재 상태

- 이동과 입력을 확인한 초기 프로토타입임.
- 제목과 달리 사격 게임 전체가 완성된 상태는 아님.

## 실행 방법

1. Unreal Engine 5.4에서 `ShootingProject.uproject`를 열면 됨.
2. `MainMap`을 열고 Play를 누르면 됨.
